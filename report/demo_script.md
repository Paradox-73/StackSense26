# StackSense demo video script (target 2:53, allowed 2:30 to 2:55)

Presenter and voice: Kanav Bhardwaj, recording it himself in his own voice. No synthetic voice, no stock footage, no music, no face camera.

The video is a story. It opens with a project typed in plain words and read into answers, with the plain-English summary the engine checks. Then come two real projects (the first one also shows a hard rule at work), the case where the user does not know an answer, and the proof. It does not tour features one by one.

Pace rule: at most 2.5 spoken words per second in every shot. The check in `tests/test_demo_script.py` counts every number as 3 words, so a line that passes it is slower than 2.5 words a second when read aloud.

Other claims shown on screen, each checked by the test:

- Typed description (opening): "We are 3 students building a ticketing site for our college fest, about 20,000 visitors a day, ₹5,000 a month for hosting. We know React and Node." With the key set the note under the button reads "Language model: on (gemini-3.5-flash-lite)", but the model adds nothing for this text, so all six answers carry the "rule" badge: daily users (20,000), team size (3), budget (5,000), currency (INR), skills (React, Node.js) and platform (web), each with the words it came from. The engine then picks React SPA, Node.js + Express, PostgreSQL and Cloudflare Pages + Workers, and shows the cost ₹5,280–₹40,800 with "over budget · ₹5,000". Three questions stay open: what you are building, compliance rules, where it must run.
- With the key set the summary for this stack is badged "checked against engine facts" (the model's text passed the check; its reply is saved in `data/llm_cache/`, so the take repeats it).
- The summary panel is badged "checked against engine facts" when the model's text passed the check, and "template fallback" when it did not or when no key is set. The model fills nothing that is not quoted from the text and picks nothing.

- Why not Netlify (case 1, hosting): "Netlify is ruled out by your answers: Netlify: No HIPAA Business Associate Agreement available.", "its best stack is 7.8 stack points below the recommendation", "(approximate: scored despite a hard constraint)".
- Case 2 backend card: "Structure for large teams 5.0/5 vs 3.2 avg" and "25 engineers need enforced conventions".
- Not sure on daily users (Startup SaaS MVP): "Robust: Frontend, Database, Hosting." Backend: Supabase up to 1M/day, Node.js + Express from 10M/day.
- Growth path (TrailNotes, content_site): the panel reruns the engine at 1×, 3×, 10×, 30× and 100× the 20,000 daily users and shows 1×, 10× and 100×. Frontend (Next.js), backend (no server code) and database (none) stay; hosting is Netlify at 1× and Cloudflare Pages + Workers from 10× (about 200k users), with cost $0 throughout.
- Terminal: 1061 tests pass; the benchmark held-out table ends with `all 29/40 = 72% 38/40 = 95%` and the all-briefs table with `154/160 = 96%`.
